INSTALL ON ANOTHER ANDROID PHONE OR TABLET
1. Open the public download page in that device's browser.
2. Download Stride.apk under Assets.
   Do not choose Source code (zip/tar.gz). No GitHub account is required.
3. Open the downloaded APK. If prompted, open Settings and allow installs
   from that source (your browser or Files), then return and tap Install.
4. Open Stride and allow notifications. In Settings, choose the reminder
   time and test the coach's voice. Set the voice separately on each device.
5. For outdoor routes, enable Record outdoor GPS and allow precise location.

Android 8.0 or later is required. This is the signed personal debug build,
version 1.6.1 (code 10). No Play Store account, GitHub account, or login inside
Stride is needed. The installer is public; your workouts stay on your device
and are not included in the download. Devices do not synchronize workouts.

If Android specifically asks for developer verification, additional setup
may apply on that device. See Google's current instructions:
https://support.google.com/android/answer/17588095
Managed devices may restrict installations outside their approved store.

UPDATING
In Stride 1.6 and later, open Settings → Updates → Allow Stride updates,
then turn on Android's Allow from this source switch. This is a one-time
setup on each device. Automatic updates and Wi-Fi-only downloads start on.
Stride checks while open, downloads and verifies the newer APK, and gives
you a 10-second countdown before installing. Choose Update later to postpone
for 24 hours. No installation happens during running or paused workouts.
The app may close during installation; open it again to continue. Android
may ask for confirmation. Checks resume when Stride is open; there is no
periodic checking while the app is closed. Use Check now to retry immediately.
You can disable automatic updates or Wi-Fi-only downloads in Settings.

The public download page still works for manual installation. Install updates
over Stride; do not uninstall first. Compatible updates preserve local data.
Save a full backup before changing phones or uninstalling.

SETTING UP A REPLACEMENT PHONE
The installer contains the app, not your personal workout history.
On the old phone: Settings → Save full backup. Keep the resulting JSON file
on your Mac or another device so it survives loss of the phone.
On the new phone: install Stride, transfer that backup file, then select
Settings → Restore from backup and confirm the replacement.
Without a saved backup, reinstalling starts a new program. Devices do not
synchronize, and restoring replaces current data rather than merging it.

DURING YOUR WORKOUT
Start your audiobook or podcast, then start the workout. Stride can run with
the screen locked. Callouts request a brief pause and release audio focus
when finished; the other player must honor Android audio focus.
Headphone playback controls do not pause the workout.
Use Stride's notification or Quick Settings workout tile to pause/continue.
Callout volume in Settings controls speech relative to phone media volume.

AFTER YOUR WORKOUT
Progress → the workout shows its route on online street maps (viewed tiles
are cached), time, distance, and export options. GPS recording works without
map access. Local diagnostic reports can be exported or retrieved by USB.
